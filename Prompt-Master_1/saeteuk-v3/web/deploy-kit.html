세특 도우미 배포 키트

선생님이 마스터 스프레드시트를 한 번 만들고, 그 링크를 동료 선생님들께 보내는 데 필요한 것이 이 페이지에 다 있습니다. 코드는 버튼으로 복사되고, 공유 링크를 붙여넣으면 보낼 링크와 메시지가 만들어집니다.

1. 마스터 만들기

선생님 한 분이 딱 한 번

  1. 새 스프레드시트를 엽니다

    아래 버튼을 누르면 빈 스프레드시트가 새 탭으로 열립니다. 이 페이지는 그대로 두세요.

    새 스프레드시트 열기 ↗
    다른 학교 선생님께도 보낼 거라면 개인 구글 계정으로 만드세요. 교육청·학교 계정은 바깥 공유나 스크립트 실행이 막혀 있는 경우가 있습니다.

  2. 파일 이름을 바꿉니다

    왼쪽 위 제목 없는 스프레드시트를 눌러 세특 작성 도우미 v3로 바꿉니다. 받는 선생님 사본에 이 이름이 따라갑니다.

  3. Apps Script 편집기를 엽니다

    상단 메뉴 확장 프로그램 → Apps Script. 새 탭에 코드 편집기가 열리고, Code.gs에 function myFunction() {}이 들어 있습니다.

  4. Code.gs 를 붙여넣습니다

    아래 버튼으로 복사한 뒤, 편집기의 기존 내용을 Ctrl+A로 전부 선택하고 Ctrl+V로 덮어씁니다. 맥은 ⌘입니다.

  5. HTML 파일 5개를 만듭니다

    왼쪽 파일 옆의 + → HTML → 이름 입력 → 엔터. 새 파일의 기존 내용을 지우고 붙여넣습니다. 다섯 번 반복합니다.

    이름은 아래 표기 그대로, .html 없이 적어야 합니다. 한 글자라도 다르면 팝업이 열리지 않습니다.

  6. 저장합니다

    Ctrl+S 또는 위쪽 디스크 아이콘. 왼쪽 파일 목록에 Code.gs와 HTML 5개, 모두 6개가 보이면 맞습니다.

  7. 스프레드시트로 돌아가 새로고침합니다

    스프레드시트 탭에서 F5. 5~10초 뒤 상단에 세특 도우미 v3 메뉴가 생깁니다.

  8. 메뉴 ① 처음 설치 를 누릅니다

    세특 도우미 v3 → ① 처음 설치 / 구조 복구

    처음이라 승인 화면이 뜹니다.
    [계속] → 계정 선택 → "Google에서 확인하지 않은 앱" 화면에서 왼쪽 아래 [고급] → [세특 작성 도우미(안전하지 않음)(으)로 이동] → [허용].
    승인이 끝나도 설치가 바로 안 될 때가 많습니다. 그러면 메뉴를 한 번 더 누르세요.

  9. 탭이 생겼는지 확인합니다

    아래쪽에 🚀 시작하기 📖 사용법 ⚙️ 설정 👤 학생명단 🗂 활동목록 🧩 기록종류 📚 교과영역 📐 공통규칙 탭이 보이면 마스터 완성입니다. 시트1은 지워도 됩니다.

  10. 마스터는 비워 둡니다

    여기에 학생 명단, 활동, 생성 결과를 넣지 마세요. 사본을 받는 선생님께 그대로 복사됩니다. 직접 써 보고 싶으시면 이 마스터에서 사본을 하나 더 만들어 거기서 쓰세요.

2. 공유 링크 만들기

받는 사람에게 [사본 만들기] 창이 바로 뜨는 링크

  1. 마스터를 공유로 엽니다

    오른쪽 위 공유 → 일반 액세스를 링크가 있는 모든 사용자로 → 역할은 뷰어 → 링크 복사 → 완료.

    뷰어로 두어야 원본이 안전합니다. 받는 선생님은 원본을 고칠 수 없고 사본만 만들 수 있습니다.

  2. 복사한 링크를 여기에 붙여넣습니다

    링크를 붙여넣으면 여기에 만들어집니다.
    직접 열어서 확인 ↗
    …/d/파일ID/edit?usp=sharing
    → …/d/파일ID/copy
    [직접 열어서 확인]을 눌러 보세요. [사본 만들기] 창이 뜨면 성공입니다. 여기서는 실제로 복사하지 않아도 됩니다.

3. 선생님들께 보내기

메신저·업무포털에 그대로 붙여넣으세요

승인 화면에서 제일 많이 멈추기 때문에, 넘는 법을 메시지에 함께 적어 두었습니다. 문구는 자유롭게 고치셔도 됩니다.

알아 두실 것

코드, 시트, 서식, 기록종류·교과·공통규칙 프리셋사본에 따라감
AI 키 — 각자 자기 구글 계정에 저장되므로 의도된 동작따라가지 않음
자동 생성 트리거 — 필요하면 받은 사람이 메뉴 ⑥에서 켬따라가지 않음
수업관찰 웹앱 배포 — 쓸 사람만 각자 한 번따라가지 않음

코드를 고치면?

새 버전을 받으면 이 페이지도 새로 만들어 드립니다. 마스터의 Apps Script에서 Code.gs(와 바뀐 HTML)만 다시 붙여넣고 저장하면 마스터가 갱신되고, 그 뒤로 사본을 만드는 선생님은 새 버전을 받습니다.

이미 사본을 만든 선생님의 파일은 자동으로 바뀌지 않습니다. 사본은 그 순간 코드까지 통째로 복제되어 따로 떨어져 나가기 때문입니다. 큰 변경이 있을 때만 "새 링크로 다시 사본 만들어 주세요"라고 안내하시면 됩니다.
