# 개인정보와 비용

학생 정보를 다루는 도구입니다. 배포 전에 읽고, 함께 쓰는 선생님들께도 알려 주세요.

---

## 어떤 데이터가 어디로 가나

| 데이터 | 어디에 있나 | 외부 AI로 전송되나 |
|---|---|---|
| 반·번호·이름 | 본인 구글 드라이브의 스프레드시트 | **이름은 기본적으로 전송되지 않음**. 반·번호도 전송되지 않음 |
| 성취수준(등급) | 같은 스프레드시트 | 과세특 등 `성취수준 사용`이 켜진 기록에서만 숫자로 전송 |
| 활동 입력 자료 | 같은 스프레드시트 | **전송됨** — 세특 생성의 재료 |
| 생성 결과 | 같은 스프레드시트 | — |
| API 키 | 실행하는 사람의 구글 계정(`UserProperties`) | 해당 AI 서비스 인증에만 사용 |

`⚙️ 설정 > 학생 이름 마스킹`이 `TRUE`(기본값)이면 학생 이름이 프롬프트에 포함되지 않습니다. **끄지 마세요.** 이름이 있다고 결과가 좋아지지 않습니다. 오히려 나이스 기재 규칙상 이름은 쓰면 안 됩니다.

---

## 입력하면 안 되는 것

활동 입력 칸에 다음을 넣지 마세요. 외부 AI 서비스로 전송됩니다.

- 주민등록번호, 학번 외 식별번호, 연락처, 주소
- 가정환경·경제 사정·한부모·다문화 등 가족 관련 정보
- 건강 상태, 진단명, 복약, 상담·치료 이력
- 징계·선도 이력, 학교폭력 관련 사항
- 그 밖에 학생이 알면 곤란해할 내용

세특에 들어가면 안 되는 내용은 애초에 입력 칸에도 넣지 않는 것이 원칙입니다.

---

## API 키

- **저장 위치**: `PropertiesService.getUserProperties()` — 스프레드시트가 아니라 **실행하는 사람의 구글 계정**에 묶입니다.
- 따라서 사본을 다른 선생님께 공유해도 키는 넘어가지 않습니다. 각자 자기 키를 넣어야 합니다.
- 시트 어디에도 키가 기록되지 않으므로, 실수로 시트를 공유해도 키가 노출되지 않습니다.
- 키가 유출된 것 같으면 해당 서비스 콘솔에서 즉시 폐기(revoke)하고 새로 발급하세요.

## 비용

| 방식 | 비용 | 특징 |
|---|---|---|
| Gemini API | 무료 등급 있음, 초과분 종량제 | 분당 호출 제한이 있어 여러 명 동시 생성 시 일부 실패 |
| OpenAI API | 종량제 | 모델에 따라 차이가 큼 |
| Anthropic API | 종량제 | |
| Gemini(구독) | 구독료에 포함 | 워크스페이스 Gemini / Google One AI Premium. 셀 수식으로 동작 |

**체크박스를 켜 둔 채 두지 마세요.** 자동 생성 트리거를 켠 상태에서 체크가 남아 있으면 시트를 건드릴 때마다 재호출될 수 있습니다. 결과를 `최종본`에 옮긴 뒤 체크를 해제하는 것이 습관이 되어야 합니다.

`⚙️ 설정 > 1회 최대 생성 건수`로 한 번에 처리할 인원을 제한할 수 있습니다(기본 25명). Apps Script 실행 시간 제한(6분) 때문이기도 합니다.

## 학교·교육청 지침

시도교육청마다 생성형 AI를 학교생활기록부 작성에 쓰는 것에 대한 안내가 다르고, 해마다 바뀝니다. **배포 전에 본인 교육청의 지침을 확인하세요.** 일반적으로 공통되는 원칙은 다음과 같습니다.

- AI가 쓴 문장을 검토 없이 그대로 기재하지 않는다.
- 학생 개인정보를 외부 서비스에 입력하지 않는다.
- 관찰하지 않은 사실을 기재하지 않는다.
- 최종 기재 내용에 대한 책임은 작성 교사에게 있다.

이 도구의 검증 기능은 **표현을 기계적으로 점검**할 뿐, 위 원칙을 대신 지켜 주지 않습니다.

## 데이터 삭제

- 스프레드시트를 지우면 학생 자료와 결과가 함께 사라집니다.
- API 키만 지우려면 메뉴 `② AI 연결 설정`에서 해당 칸에 공백 한 칸을 넣고 저장하거나, Apps Script 편집기에서 다음을 실행하세요.

```javascript
function clearMyKeys() {
  PropertiesService.getUserProperties().deleteAllProperties();
}
```

- 학년도가 끝나면 학생 자료가 든 파일을 그대로 두지 말고, 학교 규정에 따라 보관 또는 삭제하세요.
