# v2 → v3 이관 가이드

v3는 시트 구조가 v2와 다릅니다. **기존 v2 파일을 덮어쓰지 말고 새 파일에 설치한 뒤, 필요한 내용만 옮기세요.**

---

## 권장 순서

### 1. v2 파일은 그대로 둡니다

이번 학기에 이미 v2로 작업 중이라면 끝날 때까지 v2를 쓰세요. v3는 다음 활동부터 적용하는 편이 안전합니다.

### 2. 새 스프레드시트에 v3를 설치합니다

`README.md`의 설치 절차를 따릅니다. 설치 직후에는 학생도 활동도 없는 빈 상태입니다.

### 3. 학생 명단을 옮깁니다

v2 `학생명단` 시트의 반/번호/이름/등급을 복사해 v3 `👤 학생명단`의 3행부터 **값으로 붙여넣기**(Ctrl+Shift+V) 합니다. 메뉴 `③ 학생 명단 동기화`.

### 4. 활동을 다시 만듭니다 — 프롬프트는 옮기지 않습니다

여기가 핵심입니다. **v2의 프롬프트 본문을 v3로 복사하지 마세요.** v3는 프롬프트를 조립하므로, 옮겨야 할 것은 프롬프트가 아니라 그 안에 들어 있던 *정보*입니다.

| v2에 있던 것 | v3에서 갈 곳 |
|---|---|
| `프롬프트_활동별` H열의 프롬프트 본문 | 옮기지 않음 (엔진이 조립) |
| `입력 컬럼 정의` | 활동 만들 때 [입력 항목] |
| `바이트 제한` | `🧩 기록종류`의 글자수 (또는 활동별 글자수) |
| 프롬프트 안의 `#Context` 설명 문장 | `🗂 활동목록`의 [활동 개요] 한두 줄 |
| `ROLE` (20년 경력 수학교사…) | `🧩 기록종류`의 [역할] + `📚 교과영역`의 [역할 표현] |
| `GUIDELINES_COMMON` | `📐 공통규칙` > `WRITING_RULES` (이미 채워져 있음, 다르면 수정) |
| `MATH_COMPETENCIES` | `📚 교과영역` > 수학 행의 [역량·서술 관점] |
| `VISION_2022` | `📚 교과영역` > 공통 행에 요약 형태로 포함 |
| `BYTE_CALCULATION` | `📐 공통규칙` > `BYTE_RULE` |
| `GRADE_INSTRUCTION` | `📐 공통규칙` > `GRADE_RULE` |
| 예시 시트의 입력·결과 | 새 `활동명 ▸예시` 시트에 값으로 붙여넣기 |

실제로는 **메뉴 `④ 활동 만들기 (AI 마법사)`에 v2 프롬프트의 `#Context` 부분을 그대로 붙여넣고 "이런 활동입니다"라고 설명**하는 게 제일 빠릅니다. 마법사가 입력 항목까지 알아서 제안합니다.

### 5. 기존 결과물을 옮깁니다

이미 생성해 둔 세특이 있다면, v3의 해당 활동 `▸입력` 시트의 **[최종본]** 칸에 값으로 붙여넣으세요. 반·번호가 맞는 줄에 넣으면 최종취합에 그대로 반영됩니다.

### 6. 검증을 한 번 돌립니다

메뉴 `⑦ 결과 전체 재검증`. v2로 만든 문장에 기재 금지사항이나 어미 위반이 남아 있는지 확인할 수 있습니다.

## v2 사용자가 특히 확인할 것

### 글자수가 바뀌었습니다

v2는 최종 합본을 1500바이트(500자) 하나로 관리했습니다. v3 기본값은 기록 항목마다 다릅니다.

- 진로활동: 2026학년도부터 **700자 → 500자**
- 행동특성 및 종합의견: 2026학년도부터 **500자 → 300자**

`🧩 기록종류` 시트에서 본인 학년도 기준으로 확인하세요.

### 최종 합본이 나뉩니다

v2는 모든 활동 결과를 `최종취합본_v2` 한 곳에 합쳤습니다. v3는 기록종류별로 `📦 취합 ▸과세특`, `📦 취합 ▸동아리` 처럼 나뉩니다. 과세특과 동아리를 한 문단으로 합치면 안 되기 때문입니다.

교과 세특만 쓰던 분은 `📦 취합 ▸과세특` 하나만 생기므로 체감 차이가 없습니다.

### 시트 이름 규칙이 바뀌었습니다

v2: `수행1 (확인 후 삭제)입력` → v3: `수행1 ▸입력`

시트 이름을 손으로 바꾸면 연결이 끊깁니다. 활동 이름을 바꾸려면 `🗂 활동목록`의 [활동명]을 고치세요(표시용). [활동키]와 시트 이름은 그대로 두는 편이 안전합니다.

### API 키를 다시 등록해야 합니다

v2 파일의 키는 v3 파일로 넘어오지 않습니다. 메뉴 `② AI 연결 설정`에서 다시 입력하세요.

### 자동 생성 트리거

v2의 `자동 시작 활성화`에 해당합니다. v3에서는 메뉴 `⑤ 자동 생성(체크 즉시) 켜기`. 다만 여러 명을 한꺼번에 처리할 때는 `⑤ 체크된 행 생성`이 더 빠르고 실패가 적습니다.

---

## 되돌리기

v3 설치는 새 파일에서 하므로 v2는 손상되지 않습니다. v3가 맞지 않으면 그냥 v2로 돌아가면 됩니다.

v3 안에서 시트를 실수로 지웠다면 메뉴 `① 처음 설치 / 구조 복구`를 실행하세요. 이미 있는 시트의 내용은 보존됩니다.
