## 실제 시트에서 확인할 것 (사용자)

1. 사본에서 ① 처음 설치 / 구조 복구 → 권한 다시 승인(범위가 늘어 다시 묻는다) → [📏 기재요령] 시트, [🧩 기록종류]의 [기재 주의] 칸, 공통규칙 NEIS_RULES 가 2026 문구로
2. [🚀 시작하기] 시트 버튼 4개가 눌리는지(컴퓨터 브라우저)
3. 메뉴가 잘리지 않는지(작은 노트북 화면)
4. 키를 지운 계정(또는 다른 선생님 계정)으로 시작하기 → [키 없이] → 바로 쓰기 시트 → ⑥ → 복사 → Gemini 학교 계정 → 붙여넣기
5. 🔍 검사 사이드바: 셀 가져오기 · 다시 넣기, `=SAETEUK_CHECK(A1)`
6. 학교 계정에서 구독 확인(시험 셀 [생성 및 삽입])

## 계정 연결(구독으로 쓰기) 조사 — 2026-10 다시 확인

- 학교 계정 `=AI()`: Google AI Pro for Education 부가 서비스에 포함. Education Fundamentals·Standard 는 없음, Education Plus·Teaching and Learning 에는 "몇 달 안에"(2026-02 발표, 확인 안 됨). 한국어 지원. 결과는 [생성 및 삽입]을 사람이 눌러야 함.
- **Gemini 앱(gemini.google.com)은 모든 Workspace for Education 판에서 무료**, 학교 계정은 대화가 AI 학습·사람 검토에 쓰이지 않음(관리자가 켜야 함). → 키 없는 선생님의 기본 경로를 "키 없이(복사·붙여넣기)"로.
- 스크립트가 구독으로 Gemini API 를 부르는 공식 방법은 여전히 없음(Vertex AI 고급 서비스는 결제한 GCP 프로젝트 필요).
