# 세특 작성 도우미 v3

학교생활기록부 특기사항을 활동 단위로 모으고, **프롬프트를 자동으로 조립해** AI에게 맡기는 구글 스프레드시트 도구입니다.

v2는 수학 교과 세특 전용이었습니다. v3는 **교과와 무관하게**, 그리고 **과세특·창체(자율·동아리·진로)·행동특성 및 종합의견**까지 같은 틀로 다룹니다.

> ⚠️ AI가 쓴 문장을 그대로 기재하지 마세요. 이 도구는 초안을 만들고 기계적으로 점검할 뿐이며, 사실 확인과 최종 문장에 대한 책임은 작성자에게 있습니다.

**받는 사람은 링크 하나만 누르면 됩니다.** 사본을 만들면 코드까지 통째로 복사되고, 사본에서 [🚀 시작하기]를 누르면 팝업이 첫 세특이 나올 때까지 안내합니다. 아래 "설치" 참고.

저장소: <https://github.com/sced9120/Prompt-Master>  ·  라이선스 MIT  ·  버그 제보와 개선 제안은 Issues로 받습니다.

## 왜 v3인가 — v2에서 바꾼 것

### 문제 1. 활동마다 프롬프트 전체를 사람이 관리했다

v2의 `프롬프트_활동별` 시트는 활동마다 프롬프트 **본문 전체**를 담고 있었습니다. 새 활동을 만들려면 기존 프롬프트를 복사해 고쳐야 했고, 그 결과 등록된 세 활동의 골격이 이미 서로 달랐습니다.

| | 수업관찰 | 구글설문지 | 수학 문항 제작 |
|---|---|---|---|
| `#Examples` 섹션 | 없음 | 있음 | 있음 |
| 섹션 제목 표기 | `{VISION_2022}` 만 | 동일 | `#2022 개정 교육과정…` 제목을 덧붙임 |
| 마무리 지시문 | 없음 | 있음 | `지금 이 학생의 등급은` 에서 문장이 끊김 |
| 분량 | 본문에 "300바이트" 하드코딩 | "750바이트" 하드코딩 | "700바이트" 하드코딩 |

분량이 G열(`바이트 제한`)과 프롬프트 본문 **두 곳**에 있어서, 한쪽만 고치면 조용히 어긋났습니다.

**v3의 해법 — 프롬프트를 7개 슬롯으로 쪼개고 엔진이 조립합니다.**

```
① 역할       ← 기록종류.역할  ×  교과영역.역할 표현
② 과제       ← 기록종류.목표  +  활동명 · 활동 개요
③ 서술 규칙  ← 공통규칙.WRITING_RULES
④ 기재 금지  ← 공통규칙.NEIS_RULES
⑤ 관점·역량  ← 기록종류.서술 관점  +  교과영역.역량
⑥ 분량       ← 글자수 한 곳에서만 관리 → 문장 자동 생성
⑦ 활동 고유  ← 입력 형식 + 예시 + (성취수준 지침) + 마무리 지시문
```

교사가 채우는 것은 **활동 개요 한두 줄과 입력 항목**뿐입니다. 어미를 바꾸고 싶으면 `📐 공통규칙` 한 칸만 고치면 모든 활동에 동시에 반영됩니다.

### 문제 2. 프롬프트를 처음부터 써야 했다 — 가장 큰 진입장벽

**v3: 활동 만들기 AI 마법사.** 활동을 편한 말로 설명하면 AI가 입력 항목·활동 개요·예시 초안을 제안하고, [이 활동 만들기]를 누르면 입력 시트와 예시 시트가 한 번에 만들어집니다. 마음에 안 들면 "협업한 부분도 항목에 넣어 주세요" 처럼 말로 고칩니다.

### 문제 3. 수학 전용 문구가 공통 영역에 박혀 있었다

`ROLE`이 "20년 경력의 고등학교 **수학교사**", `MATH_COMPETENCIES`가 수학과 역량 — 둘 다 `프롬프트_공통`에 있었습니다. 다른 교과 교사는 어디를 고쳐야 하는지 알기 어려웠습니다.

**v3: 세 층으로 분리.**

- `🧩 기록종류` — 항목별 글자수·관점·성취수준 사용 여부 (6종 기본 제공)
- `📚 교과영역` — 교과별 역량 (수학·국어·영어·과학·사회·정보·체육·예술·진로 + 창체용 `공통`)
- `📐 공통규칙` — 교과와 무관한 것만 (어미, 기재 금지사항, 바이트 계산법)

교과를 추가하려면 `📚 교과영역` 맨 아래에 한 줄 추가하면 끝입니다.

### 문제 4. 등급이 모든 기록에 전제되어 있었다

`GRADE_INSTRUCTION`이 5등급 상대평가를 전제했지만, 동아리·자율·진로·행동특성에는 성취수준 개념이 없습니다. v3는 `기록종류.성취수준 사용` 체크박스로 켜고 끕니다. 과세특에만 기본 켜짐.

### 문제 5. 최종 취합이 전부 한 덩어리였다

과세특과 동아리활동은 나이스에서 **서로 다른 칸**에 들어갑니다. 한 덩어리로 합쳐 1500바이트로 압축하면 안 됩니다.

**v3: 취합 시트를 기록종류별로 나눕니다.** `📦 취합 ▸과세특`, `📦 취합 ▸동아리`, `📦 취합 ▸행발` … 각각 자기 글자수로 압축합니다.

### 문제 6. 기재요령 위반을 막는 장치가 없었다

v3는 생성 직후 자동으로 점검하고 `검증` 칸에 표시합니다.

- **분량** — 바이트 초과, 지나친 부족
- **기재 금지** — 수상·등수, 공인어학시험, 자격증, 논문·특허, 모의고사, 해외활동, 학원·사설기관, 부모 정보
- **형식** — 존댓말·평서형 어미, `학생은` 주어, 금지 특수문자

`[수정]`은 반드시 고칠 것, `[확인]`은 맥락에 따라 괜찮을 수도 있는 것입니다.

### 문제 7. 예시를 관리할 방법이 없었다

예시는 결과 품질에 가장 크게 작용하는 입력입니다. 동시에 가장 위험한 입력이기도 합니다. **AI는 예시의 표현을 그대로 따라 씁니다.** 예시에 "수상"이나 "○○대학교"가 남아 있으면 그 표현이 모든 학생 결과에 번집니다. v2에는 예시를 점검할 장치가 없었습니다.

**v3의 예시 관리**

- **예시 칸 늘리기** — 기본 3칸, 메뉴에서 원하는 만큼 추가. 프롬프트에는 앞에서부터 최대 8개까지 들어갑니다(호출 비용 상한).
- **예시 더 만들기 (AI)** — 이미 써 둔 예시의 문체를 따라가면서 소재와 수준이 겹치지 않는 초안을 만듭니다. 성취수준을 쓰는 기록이면 잘한 학생과 아직 부족한 학생이 섞이도록 지시합니다.
- **예시 검증** — 예시 자체를 분량·기재 금지사항·어미 기준으로 점검합니다. 몇 개가 실제로 프롬프트에 들어가고 몇 바이트인지도 함께 보여 줍니다.
- 마법사에서 활동을 만들 때 예시를 1~3개 함께 생성할 수 있고, 만들어진 예시는 예시 시트에 그대로 저장됩니다.

AI가 만든 예시는 초안입니다. 실제 수업과 맞지 않는 내용이 섞일 수 있으니 반드시 손보고 쓰세요.

### 그 밖에

- **API 키를 `UserProperties`에 저장** — 사본을 공유해도 키가 넘어가지 않고, 시트 어디에도 기록되지 않습니다.
- **학생 이름 마스킹 기본 켜짐** — 이름이 AI로 전송되지 않습니다.
- **2026학년도 글자수 반영** — 진로활동 700→500자, 행동특성 및 종합의견 500→300자.
- **Anthropic(Claude) 지원 추가** — OpenAI / Gemini / Gemini 구독(`=AI()`)과 함께 4가지.
- **일괄 생성** — 체크박스 트리거 대신 [체크된 행 생성] 메뉴로 한 번에. 트리거 설정 없이도 동작하고 더 안정적입니다.

## 설치

경로가 둘입니다. **동료 선생님은 A만 보면 됩니다.** B는 배포하는 사람이 한 번만 하는 일입니다.

### A. 쓰는 사람 — 링크 하나 (3분)

1. 공유받은 링크를 엽니다 → **[사본 만들기]** 창이 바로 뜹니다 → 누릅니다
2. 내 사본이 열립니다. 첫 탭 **🚀 시작하기** 에 안내가 있습니다
3. 상단 메뉴 **[세특 도우미 v3] > [🚀 시작하기]**
4. 팝업이 순서대로 안내합니다 — 구조 설치 → AI 키 → 학생 명단 → 첫 활동 → 시험 생성

중간에 창을 닫아도 다시 열면 끝난 단계는 `완료`로 표시되고 그다음부터 이어집니다.

> **처음 한 번만 겪는 관문**
> 메뉴를 처음 누르면 구글이 승인을 요구하고, **"Google에서 확인하지 않은 앱입니다"** 화면이 뜹니다.
> `[고급]` → `[세특 작성 도우미(안전하지 않음)(으)로 이동]` → `[허용]` 순서로 넘어가면 됩니다.
> 개인이 만든 스크립트는 구글 심사를 받지 않아 모두 이 화면이 나옵니다. 여기서 제일 많이 멈추므로,
> 링크를 보내실 때 이 문장을 같이 적어 주시면 좋습니다.

필요한 것은 **AI 키 하나**와 **학생 명단**뿐입니다. Gemini 키가 가장 부담이 적습니다(aistudio.google.com, 무료 등급 있음).

### AI 모델 — 직접 적고, 시험하고, 고르기

기본 모델은 **`gemini-flash-latest`** 입니다. 구글이 새 Flash 모델을 낼 때마다 자동으로 그 모델을 가리키므로,
배포한 사본이 1~2년 뒤에도 "모델을 찾을 수 없음"으로 멈추지 않습니다.

- 모델 목록은 `⚙️ 설정` 시트 아래 **🤖 모델 목록** 표에 있고, 이 표가 모든 `[모델]` 드롭다운의 선택지입니다.
- 메뉴 `② AI 연결 · 모델 설정 > [② 모델]` 에서 이름을 직접 적고 **[시험]** 을 누르면 ✓/✗ 와 걸린 시간이 남습니다.
  ✗ 이면 이유(모델명 오류 · 무료 등급 불가 · 한도 초과 · 키 오류)를 우리말로 알려 줍니다.
- `[③ 도움말] > [목록 불러오기]` 는 저장된 키로 **내가 쓸 수 있는 모델**을 회사에 직접 물어 옵니다(호출 비용 없음).

| 수준 | 예 | 이럴 때 |
|---|---|---|
| ★ 충분 (기본) | `gemini-flash-latest` · `gpt-5.6-luna` · `claude-haiku-4-5` | 과세특·창체·행발 거의 모든 경우 |
| 가볍게 | `gemini-flash-lite-latest` | 행발처럼 짧은 글, 한 번에 많은 학생 |
| 고급 | `gemini-pro-latest` · `gpt-5.6-terra` · `claude-sonnet-5` | 합본 압축이 글자수를 자꾸 넘길 때만 |

결과 품질은 모델 등급보다 **예시와 학생 자료**가 훨씬 크게 좌우합니다.
최신 모델명: [Gemini](https://ai.google.dev/gemini-api/docs/models) · [OpenAI](https://platform.openai.com/docs/models) · [Claude](https://platform.claude.com/docs/en/models/overview) (2026년 9월 기준으로 확인)

### B. 마스터 사본 만들기 — 배포하는 사람, 한 번만

> **가장 쉬운 방법: [`web/deploy-kit.html`](web/deploy-kit.html) 을 브라우저로 여세요.**
> 아래 절차가 체크리스트로 정리되어 있고, 붙여넣을 코드 5개가 버튼 하나로 복사됩니다.
> 공유 링크를 붙여넣으면 `/copy` 링크와 선생님들께 보낼 안내 메시지까지 만들어 줍니다.
> 코드를 고친 뒤에는 `npm run kit` 으로 이 페이지도 다시 만드세요.

손으로 하려면:

1. 이 저장소를 받습니다

   ```bash
   git clone https://github.com/sced9120/Prompt-Master.git
   ```

   `Code > Download ZIP` 도 됩니다.

2. 빈 구글 스프레드시트를 만들고 `확장 프로그램 > Apps Script` 를 엽니다

3. **`dist/` 의 파일 5개**를 붙여넣습니다. (`apps-script/` 의 모듈 파일 15개를 하나로 합쳐 둔 것입니다)

   | 붙여넣을 곳 | 파일 |
   |---|---|
   | `Code.gs` (내용 전부 지우고) | `dist/Code.gs` |
   | HTML 새로 만들기 → `UI_Onboard` | `dist/UI_Onboard.html` |
   | HTML 새로 만들기 → `UI_ApiKey` | `dist/UI_ApiKey.html` |
   | HTML 새로 만들기 → `UI_Wizard` | `dist/UI_Wizard.html` |
   | HTML 새로 만들기 → `UI_Observe` | `dist/UI_Observe.html` |

   HTML 파일은 `파일 +` → `HTML` 로 만들고 이름에서 `.html` 은 빼고 적습니다.
   `appsscript.json` 은 `프로젝트 설정 > "appsscript.json" 매니페스트 파일 표시` 를 켜면 교체할 수 있습니다(선택).

4. 저장하고 스프레드시트로 돌아가 **새로고침** → 상단에 `세특 도우미 v3` 메뉴가 생깁니다

5. 메뉴 **① 처음 설치 / 구조 복구** 를 누릅니다 (권한 승인 필요). 기본 시트가 모두 만들어집니다

6. **마스터는 깨끗하게 둡니다.** 학생 명단, 활동, 생성 결과, API 키를 넣지 마세요.
   사본을 받는 사람이 자기 것으로 채웁니다

7. 우상단 **공유** → `링크가 있는 모든 사용자` → 권한 **뷰어** → 링크 복사

8. 복사한 링크 끝의 **`/edit?usp=sharing` 을 `/copy` 로 바꿉니다**

   ```
   https://docs.google.com/spreadsheets/d/<파일ID>/edit?usp=sharing
   →  https://docs.google.com/spreadsheets/d/<파일ID>/copy
   ```

   이 링크를 열면 **[사본 만들기] 창이 바로 뜹니다.** 원본은 열리지 않으니 망가질 걱정이 없습니다

9. 이 `/copy` 링크를 배포합니다

### 사본에 따라오는 것 / 따라오지 않는 것

| | 사본 복사 시 |
|---|---|
| 스크립트 코드, 시트, 서식, 프리셋 | **따라옴** |
| API 키 | 따라오지 않음 (각자 계정에 저장되므로 — 의도된 동작) |
| 자동 생성 트리거 | 따라오지 않음 → 필요하면 메뉴 `⑥ 자동 생성 켜기` 를 각자 한 번 |
| 수업관찰 웹앱 배포 | 따라오지 않음 → 쓸 사람만 `부가 기능 > 배포 안내` 대로 각자 한 번 |

### 코드를 고쳤다면

```bash
node tools/build.js   # apps-script/ → dist/ 합본 다시 만들기
npm test              # 고치기 전에 한 번, 고친 뒤에 한 번
```

개발은 `apps-script/` 의 모듈 파일에서 하고, 마스터에 반영할 때만 `dist/Code.gs` 를 붙여넣습니다.
`dist/` 를 직접 고치면 다음 빌드 때 덮어써집니다.

기존 v2 파일에서 옮겨 오는 경우는 [이관 가이드](docs/MIGRATION-v2-to-v3.md)를 보세요.

## 쓰는 흐름

```
학생명단 ──┐
           ├─→ [활동 ▸입력]  ─ 생성 ─→  AI 결과 ─ 손질 ─→ 최종본
활동 만들기 ┘        ↑                                      │
   (마법사)      [활동 ▸예시]                                │
                                                            ▼
                                        📦 취합 ▸기록종류  ─ 압축 ─→ 나이스
```

1. `활동명 ▸예시` 시트에 모범 예시를 채웁니다. **결과 품질을 가장 크게 좌우합니다.**
   칸이 모자라면 `⑤ 예시 칸 늘리기`, 막막하면 `⑤ 예시 더 만들기 (AI)`, 다 쓴 뒤엔 `⑤ 예시 검증`.
   서로 다른 수준과 소재로 3~5개 정도가 적당합니다.
2. `활동명 ▸입력` 시트 노란 칸에 학생 자료를 넣습니다.
3. `생성`을 체크한 뒤 메뉴 `⑥ 체크된 행 생성`. `[모델]` 칸을 비우면 설정의 활동용 모델을 씁니다.
4. `AI 결과`를 읽고 고쳐 파란 `최종본` 칸에 넣습니다.
5. 메뉴 `⑦ 최종취합 시트 생성/갱신` → 한도를 넘는 학생만 `압축` 체크 → `최종 압축본 생성`.

## 스프레드시트 없이 쓰기

프롬프트만 필요하다면 **[세특 프롬프트 공방](web/prompt-studio.html)** 을 브라우저에서 열면 됩니다(저장소를 내려받은 뒤 그 파일을 더블클릭하면 바로 뜹니다). 기록 종류와 교과를 고르고 활동을 정의하면 같은 엔진으로 프롬프트가 조립되고, 완성된 문장의 분량·기재요령 점검도 됩니다. 설치도 로그인도 필요 없고, 입력한 내용은 그 브라우저에만 남습니다.

## 개인정보와 비용

자세한 내용은 [docs/PRIVACY.md](docs/PRIVACY.md).

- 학생 **이름은 기본적으로 AI에 전송되지 않습니다**(`⚙️ 설정 > 학생 이름 마스킹`).
- API 키는 실행하는 사람의 구글 계정에만 저장됩니다. 사본을 공유해도 넘어가지 않습니다.
- 주민등록번호, 가정환경, 건강 정보 등 민감정보는 입력하지 마세요.
- 유료 API는 호출한 만큼 과금됩니다. 결과 확인 후 체크박스를 해제하세요.
- 학교·교육청의 생성형 AI 활용 지침을 먼저 확인하세요. 시도교육청마다 다릅니다.

## 개발

```bash
npm test      # 엔진 단위 테스트 50개 + 시트 정합성 검사 22개
npm run build # apps-script/ 15개 파일 → dist/Code.gs 한 개로 합치기
```

`00_Presets.gs` 와 `10_Engine.gs` 는 순수 자바스크립트로, Apps Script와 Node 양쪽에서 돌아갑니다. 프롬프트 조립 규칙을 바꿀 때는 테스트를 먼저 돌려 보세요.

`schema.test.js` 는 실제 스프레드시트 없이도 잡을 수 있는 실수를 막습니다. 시트에 쓰는 헤더 이름과 코드가 찾는 이름이 어긋나면 실행 중에는 "값이 조용히 빈 채로" 동작하기 때문입니다.

구조와 설계 의도는 [docs/PROMPT-ARCHITECTURE.md](docs/PROMPT-ARCHITECTURE.md) 를 보세요.
