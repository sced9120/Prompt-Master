✍️ 바로 쓰기
입력 항목 없이 학생마다 [관찰 메모] 한 칸. 직접 쓴 글의 검사만 해도 됩니다.
📄 보고서 세특
학생 보고서(본문·파일 링크) → AI가 요점 뽑기 → 선생님 확인 → 예시를 따라 세특.
💎 Gem으로 쓰기
Gemini 앱(구독·학교 계정)에 이 시트의 규칙을 Gem으로 저장하고, Gem이 쓴 글을 붙여 넣어 검사.
예) 1학기 수학 메모, 통합과학 실험 보고서 — 시트 이름은 "이름 ▸입력"이 됩니다.
학생마다 [관찰 메모]에 자유롭게 적고 [생성] → 메뉴 ⑥. 또는 [최종본]에 직접 쓰면 바로 검사됩니다.
빈 시트가 하나 생기고, 바로 이 창에 Gem 지침이 나옵니다. ① 지침을 복사해 Gemini에서 새 Gem을 만들고 ② Gem 대화에 학생 메모를 넣어 쓴 뒤 ③ 받은 글을 학생 줄의 [최종본]에 붙여 넣으면 [검증]이 2026 기재요령으로 바로 검사합니다. 여러 명이면 [관찰 메모]에 적고 메뉴 ⑥ → [학생 자료만 복사 (Gem 사용 시)].
① [보고서] 칸에 본문을 붙이거나 드라이브 파일 링크를 넣습니다 — 📝 구글 설문지(파일 업로드)를 연결하거나, 메뉴 ④⑤ › [보고서 폴더에서 파일 가져오기]로 한 번에.
② 메뉴 ④⑤ › [📄 보고서 요점 뽑기] → [보고서 요점]을 읽고 고칩니다. 수업에서 본 것은 [교사 관찰 메모]에.
③ 수준이 다른 3~5명은 선생님이 직접 세특을 쓰고 [⭐ 예시로 등록] → 나머지는 [생성] → 메뉴 ⑥.
파일은 구글 문서·PDF·사진·HWPX·docx를 읽습니다(.hwp 는 PDF로). 수업 중에 쓴 보고서만 쓰세요 — 학교 밖 과제형 수행평가는 2026 기재요령상 금지입니다.
Gemini › 새 Gem 만들기
① [새 Gem 만들기] → 이름(예: 세특 — 1학기 수학) → [안내]에 붙여 넣고 저장
② 그 Gem을 열고 학생 메모를 붙여 넣기 — 여러 명이면 메뉴 ⑥ 창의 [학생 자료만 복사 (Gem 사용 시)]
③ 받은 글을 시트 [최종본]에(⑥ 창이면 창에) 붙여 넣기 → [검증]이 검사
시트의 규칙·예시를 고치면 메뉴 ⑧ [AI 앱용 지침 내보내기]에서 다시 복사해 Gem의 [안내]를 바꿔 주세요. 메뉴에 Gem이 없으면 학교에서 꺼 둔 것이니 키 없이(복사·붙여넣기)로 쓰면 됩니다.
