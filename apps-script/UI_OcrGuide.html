📄 스캔 문서 → 엑셀 — 손글씨 활동지를 글자 그대로 표로

업무 인수인계 대시보드(윈도우 프로그램)의 기능입니다. 스캔 PDF·사진을 AI가 요약하지 않고 글자 그대로 읽어 표로 만들고 엑셀로 저장합니다. 헷갈리는 글자는 [불확실: 김태용/김태영]처럼 남기고 화면에 노랗게 칠해 줍니다.

① 받기·설치② AI 키③ 읽기④ 세특 시트와 함께⑤ 개인정보⑥ 막힐 때

1내려받기 · 설치 (윈도우)

⬇ 최신 버전 받으러 가기프로그램 소개 페이지
  1. 열린 페이지 아래쪽 Assets에서 WorkDashboard-Setup-(버전).exe를 받아 실행합니다(관리자 권한 필요 없음, 새 버전이 나오면 알아서 업데이트). 설치가 막힌 PC라면 WorkDashboard-Portable-(버전).exe를 받아 그 파일만 더블클릭하세요.
  2. "Windows의 PC 보호" 파란 창이 뜨면 → [추가 정보] → [실행]. 개인이 만든 프로그램이라 뜨는 안내입니다.
  3. Edge가 "일반적으로 다운로드되지 않습니다"로 막으면 Ctrl+J → 그 항목의 ⋯ → 유지. 그래도 막히면 Chrome으로 받으세요.
이 기능은 이상에 있습니다(OpenAI 키로 읽기는 v3.3.1부터). 이미 설치해 쓰고 있다면 켤 때 뜨는 업데이트 안내로 올리면 됩니다.

2AI 키 넣기 (한 번만)

  1. 프로그램 [설정] → AI 연결에서 Gemini API 키를 넣습니다. aistudio.google.com/apikey → Create API key (AIza… 로 시작).
  2. OpenAI 키만 있어도 됩니다(값싼 gpt-6-luna로 같은 방식으로 읽음). 두 키가 다 있으면 화면의 [모델]에서 골라 씁니다(Gemini 가 먼저).
  3. 이 세특 시트에 넣은 키와는 따로입니다. 프로그램이 달라서 각각 넣어야 합니다.

3읽어서 표로 만들기

  1. 왼쪽 메뉴 [자료 만들기 → 스캔 문서 → 엑셀]
  2. [파일 고르기] 또는 화면에 끌어 놓기 — PDF · PNG · JPG · WEBP · HEIC (PDF 50MB · 사진 20MB까지). 여러 파일이면 이름 차례로 한 표에 모읍니다.
  3. 추가 요청(선택) — 예) "학번 순으로", "한 학생이 한 행, 열은 이름·탐구 주제·느낀 점"
  4. 보내는 내용을 확인하는 칸을 켜고 [🔎 읽어서 표로 만들기] — 쪽수가 많으면 몇 분 걸립니다. 다른 화면으로 가도 계속 읽고, 다 읽으면 알려 줍니다.
  5. 표를 확인합니다. 노란 칸은 AI가 헷갈린 글자이니 원본과 맞춰 보세요. 취소선으로 지운 글은 빠집니다.
  6. [📥 엑셀로 저장] 또는 [📋 표 복사](엑셀·한글·이 시트에 바로 붙여 넣기)
· 반복 양식(학생별 활동지)은 학생 한 명이 한 행, 서술형 문서는 페이지마다 한 행으로 정리합니다.
· 답이 길어 끊기면 [이어서 받기] — 마지막 행 다음부터 같은 표에 붙입니다. 탭으로 문서 5개까지 따로 읽을 수 있습니다.
· 손글씨 수식은 (4 1; 2 3) · 5/3 · x²처럼 읽기 쉽게 바꿔 넣습니다. 엑셀에는 모든 칸이 글자 그대로 들어가 학번 앞 0이 사라지지 않습니다.
· 결과는 프로그램을 끄거나 탭을 닫으면 사라집니다. 꼭 엑셀로 저장하세요.

4세특 시트와 함께 쓰기 — 활동지에서 세특 초안까지

손글씨 활동지 스캔→스캔 문서 → 엑셀
학생 한 명이 한 행→[📋 표 복사]→ 이 시트의 ▸입력 노란 칸
또는 ✍️ 바로 쓰기의 [관찰 메모]→⑥ 생성 · 🔍 검사
  1. 추가 요청에 "반·번호 순으로, 한 학생이 한 행, 열은 ○○·○○"처럼 입력 시트의 열 순서를 적어 두면 붙여 넣기가 쉽습니다.
  2. 붙여 넣기 전에 학생 순서가 입력 시트(반·번호)와 같은지 확인하세요. 이름 열은 붙여 넣지 말고 학생 자료 열만 붙입니다.
  3. 학생 글은 근거 자료입니다. 2026 기재요령에 따라 세특은 교사가 직접 관찰·평가한 내용을 바탕으로 쓰고, AI 결과는 그대로 입력하지 않습니다.

5개인정보 — 꼭 읽어 주세요

· 파일 원본이 그대로 Google(또는 OpenAI)로 갑니다. 사진 속 학생 이름·학번은 미리 가릴 수 없습니다. 가려야 하면 스캔 전에 가리세요.
· 무료 등급 키로 보낸 내용은 회사가 서비스 개선에 쓰고 사람이 볼 수도 있습니다. 학생 자료는 결제를 켠(유료 등급) 키를 쓰세요.
· 학교·교육청의 생성형 AI 활용 지침을 먼저 확인하세요. 시작 전에 확인란을 켜야 읽기가 시작됩니다.
· 큰 파일(Gemini 14MB, OpenAI 30MB 넘게)은 회사 파일 저장소에 잠깐 올려 읽고, 탭을 닫거나 프로그램을 끌 때 지웁니다(파일 이름은 보내지 않음).

6막힐 때

내려받기가 안 열려요학교망에서 GitHub 가 막혀 있을 수 있습니다. 집이나 휴대폰 핫스팟에서 받아 USB로 옮기세요.
"키가 없습니다"프로그램 [설정] → AI 연결에서 Gemini(또는 OpenAI) 키를 넣고 연결 테스트.
중간에 끊겼어요[이어서 받기]. 그래도 짧으면 파일을 몇 쪽씩 나눠서 읽으세요.
표 모양이 마음에 안 들어요추가 요청에 행·열을 구체적으로 적고 다시 읽습니다. 예) "한 학생이 한 행, 열은 이름·주제·느낀 점"
아이폰 사진(HEIC)이 안 돼요OpenAI 로 읽을 때는 HEIC 를 못 읽습니다. JPG·PNG 로 바꾸거나 Gemini 키를 쓰세요.
